# Archived specs

Finished (`status: done`) and abandoned (`status: void`) specs, moved out of `specs/` so that
folder shows only live work.

Nothing in here can run. The workflow triggers on `specs/*.md` — one level, no `**` — and the
planner globs the same single level, so an archived spec is invisible to both. Moving a spec in
here is the deliberate act that retires it.

To revive one, move it back to `specs/` and set `status: ready`.
